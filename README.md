# 『AI秘書の作り方』購入者特典の配布物

Brain の教材『AI秘書の作り方』を買った人のための、Mac アプリの配布場所です。ソースコードは入っていません。

| アプリ | 版 | 置き場 |
|---|---|---|
| AI Writing Studio（原稿を書く・直す・届ける） | 0.2.0 | [Releases の aws-v0.2.0](../../releases/tag/aws-v0.2.0) |
| AI秘書の仕事部屋（AI秘書と一緒に仕事をする部屋） | 0.9.75 | [Releases の desk-v0.9.75](../../releases/tag/desk-v0.9.75) |

- どちらも Apple シリコン（M1 以降）の Mac 用で、Apple の公証を受けています。
- 入れ方は、Brain の購入者向けの案内にある「AI秘書に頼む文」を、Cursor・Codex などの AI秘書に貼るだけです。
- AI Writing Studio は、はじめて開いたときに購入者向けの案内にある「特典の合言葉」を聞きます。
